# Habeeb Birthday Story — redesigned layout

This version is a new layout inspired by the dark-brown/cream visual mockup, not just a recolour of the earlier page.

## Preview
Open `index.html` in a browser, or use VS Code Live Server.

## Add real media
Place your own images in `assets/images/`:
- `hero-photo.jpg` — dark, atmospheric hero photo (the site darkens it with an overlay)
- `first-memory.jpg` — story section
- `memory-01.jpg` through `memory-05.jpg` — gallery
- `status-memory.jpg` — optional status-related image/screenshot (avoid sharing private chats without consent)
- `letter-photo.jpg` — letter portrait/photo
- `video-poster.jpg` — optional video poster

Put a video at `assets/videos/our-memory.mp4`.

If a photo is missing, a labelled placeholder appears. The mockup itself is not the website screenshot; this is the actual coded layout.

## Edit text
Edit `index.html` to personalise the birthday letter, captions, timeline, and story details.

## Publish
Deploy the folder as a static website through Netlify or GitHub Pages. If the photos/videos are personal, remember that a public link can be forwarded.
